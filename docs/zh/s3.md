# S3 使用指南

Endpoint 默认为 `http://<s3-host>:8333`。路径风格：`http://host:8333/{bucket}/{key}`。

## 鉴权（SigV4）

设置 Access Key 后启用强制签名：

```bash
export OPENS3_ACCESS_KEY=admin
export OPENS3_SECRET_KEY=secretsecret
opens3 s3 --port 8333 --clerk http://127.0.0.1:9333 --meta-dir ./filer
# 生产多副本请用 --meta-backend postgres + DATABASE_URL（同端口亦提供 /entries /dav）
```

AWS CLI：

```bash
aws configure set default.s3.signature_version s3v4
aws --endpoint-url http://127.0.0.1:8333 s3 ls
```

未配置密钥时开发模式等价 **root**，便于 curl 调试；**生产必须开鉴权**。

## 已支持的常用 API

| 操作 | 说明 |
|------|------|
| CreateBucket / DeleteBucket / ListBuckets | 桶管理 |
| PutObject / GetObject / HeadObject / DeleteObject | 对象 CRUD |
| ListObjectsV2 | `prefix` / `delimiter` |
| CopyObject | `x-amz-copy-source` |
| CreateMultipartUpload / UploadPart / Complete / Abort | 分片上传 |
| Put/Get Bucket Versioning | 版本开关 |
| Put/Get Bucket Lifecycle | 过期规则（后台扫描） |
| Put/Get Bucket Policy | JSON IAM 风格策略 |

Admin 控制台（浏览器文件管理，无需 SigV4）：

- UI：`GET /admin` 或 `/admin/ui` — 桶列表、上传/下载/删除、文件夹浏览
- 状态：`GET /admin/api/status`
- FS API：`/admin/api/fs/buckets`、`/admin/api/fs/objects`、`/admin/api/fs/object`
- Webhook：`POST /admin/api/webhooks` `{"url":"http://..."}`
- 目录复制：`POST /admin/api/replicate` `{"prefix":"/buckets/b","target_filer":"http://other:8333"}`

## 版本控制

```bash
# 开启
curl -X PUT 'http://127.0.0.1:8333/mybucket?versioning' \
  -d '<VersioningConfiguration><Status>Enabled</Status></VersioningConfiguration>'

curl 'http://127.0.0.1:8333/mybucket?versioning'
```

开启后覆盖写会生成 `version_id`；删除可写 delete marker。

## Bucket Policy 示例

拒绝删除、允许读写：

```bash
curl -X PUT 'http://127.0.0.1:8333/mybucket?policy' \
  -H 'Content-Type: application/json' \
  -d '{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["s3:GetObject", "s3:PutObject", "s3:ListBucket"],
      "Resource": ["arn:aws:s3:::mybucket", "arn:aws:s3:::mybucket/*"]
    },
    {
      "Effect": "Deny",
      "Action": "s3:DeleteObject",
      "Resource": "arn:aws:s3:::mybucket/*"
    }
  ]
}'
```

求值规则：**显式 Deny 优先于 Allow**；`root` 身份始终放行。

## 生命周期

```bash
curl -X PUT 'http://127.0.0.1:8333/mybucket?lifecycle' \
  -d '<LifecycleConfiguration>
    <Rule>
      <ID>expire-logs</ID>
      <Status>Enabled</Status>
      <Filter><Prefix>logs/</Prefix></Filter>
      <Expiration><Days>7</Days></Expiration>
    </Rule>
  </LifecycleConfiguration>'
```

S3 进程内约每 60s 扫描并删除过期对象。

## Multipart 示例（curl）

```bash
INIT=$(curl -s -X POST 'http://127.0.0.1:8333/b/large.bin?uploads')
UPLOAD_ID=$(echo "$INIT" | sed -n 's/.*<UploadId>\([^<]*\)<\/UploadId>.*/\1/p')

curl -X PUT "http://127.0.0.1:8333/b/large.bin?partNumber=1&uploadId=$UPLOAD_ID" --data-binary @part1
curl -X PUT "http://127.0.0.1:8333/b/large.bin?partNumber=2&uploadId=$UPLOAD_ID" --data-binary @part2
curl -X POST "http://127.0.0.1:8333/b/large.bin?uploadId=$UPLOAD_ID" \
  -d '<CompleteMultipartUpload></CompleteMultipartUpload>'
```

## SDK 注意

- 区域可填 `us-east-1`（路径计算用）  
- 关闭强制 HTTPS / path-style 按 SDK 文档设置 `forcePathStyle = true`  
- 中间代理不得改写签名头  

## 静态加密（Filer）

```bash
opens3 s3 --encrypt 'your-passphrase' ...
```

对象在写入 Volume 前 AES-256-GCM 加密；口令丢失则无法解密。

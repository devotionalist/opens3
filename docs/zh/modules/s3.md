# S3（`opens3-filer` / `http_s3`）

## 作用

**S3 兼容 API**：把 AWS S3 HTTP API 翻译成路径元数据 + Volume blob。提供 SigV4、Bucket Policy、Lifecycle、Versioning、Multipart、Admin UI。与 `/entries`、`/dav` 挂在 **同一 `Server`、同一端口**（`opens3 s3` → Protocols::ALL）。

## 位置

与 Filer 同 crate，扁平在 `crates/opens3-filer/src/`：

| 文件 | 作用 |
|------|------|
| `server.rs` | 融合 `Server`（单端口） |
| `http_s3.rs` | S3 / Admin 路由 |
| `auth.rs` / `policy.rs` / `lifecycle.rs` | SigV4、策略、生命周期 |
| `xml.rs` / `error_xml.rs` / `admin_cluster.rs` | XML 与运维 API |

## 默认端口

`8333`（同端口提供 `/entries`、`/dav`、`/store`）。Admin UI：`/admin/ui`。

## 对象映射

| S3 | Filer 路径 |
|----|--------|
| Bucket `b` | `/buckets/b` |
| Object `k` | `/buckets/b/k` |
| Multipart | Store KV `ns=multipart` |
| Policy / Lifecycle / Versioning | Store KV 对应 namespace |

进程内 `BlobClient` + `FilerStore`。生产直连共享元数据库（Postgres 等）。详见 [客户端与网关](../gateways.md)。

## 请求处理流水线

```text
HTTP
  → in_flight++
  → SigV4 / 匿名身份
  → Policy allow?
  → 按 method + query 映射 action（GetObject / PutObject / multipart…）
  → FilerStore / BlobClient
  → 记 requests / duration / errors / bytes
```

## 已覆盖能力（摘要）

- Bucket：Create / Delete / List / Location / Policy / Lifecycle / Versioning  
- Object：Put / Get / Head / Delete / Copy  
- Multipart：Initiate / UploadPart / Complete / Abort  
- 鉴权：SigV4；可关鉴权做本地开发（生产务必开启）  

完整矩阵见 [S3 兼容](../s3-compat.md)、用法见 [S3 使用](../s3.md)。

## 设计要点

- **无状态**：元数据在 Store，数据在 Volume；多副本须共享 Postgres/MySQL。  
- 指标带 `action` 标签（含 `s3:CreateMultipartUpload` 等），便于按 API 看 QPS/延迟。  
- Helm 只有 `opens3-filer` Deployment，不再单独部署 S3。  

## 依赖

与 Filer 同 crate：`opens3-store`、`opens3-common`。

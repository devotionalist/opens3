# S3 (`opens3-filer` / `http_s3`)

## Role

**S3-compatible API**: translates the AWS S3 HTTP API into path metadata + Volume blobs. Provides SigV4, Bucket Policy, Lifecycle, Versioning, Multipart, and Admin UI. Mounted with `/entries` and `/dav` on the **same `Server`, same port** (`opens3 s3` → Protocols::ALL).

## Location

Same crate as Filer, flat under `crates/opens3-filer/src/`:

| File | Role |
|------|------|
| `server.rs` | Unified `Server` (single port) |
| `http_s3.rs` | S3 / Admin routes |
| `auth.rs` / `policy.rs` / `lifecycle.rs` | SigV4, policies, lifecycle |
| `xml.rs` / `error_xml.rs` / `admin_cluster.rs` | XML and ops APIs |

## Default port

`8333` (same port also serves `/entries`, `/dav`, `/store`). Admin UI: `/admin/ui`.

## Object mapping

| S3 | Filer path |
|----|------------|
| Bucket `b` | `/buckets/b` |
| Object `k` | `/buckets/b/k` |
| Multipart | Store KV `ns=multipart` |
| Policy / Lifecycle / Versioning | Store KV corresponding namespaces |

In-process `BlobClient` + `FilerStore`. Production connects directly to a shared metadata DB (Postgres, etc.). See [Clients & gateways](../gateways.md).

## Request pipeline

```text
HTTP
  → in_flight++
  → SigV4 / anonymous identity
  → Policy allow?
  → map method + path to action (GetObject / PutObject / multipart…)
  → FilerStore / BlobClient
  → record requests / duration / errors / bytes
```

## Covered capabilities (summary)

- Bucket: Create / Delete / List / Location / Policy / Lifecycle / Versioning  
- Object: Put / Get / Head / Delete / Copy  
- Multipart: Initiate / UploadPart / Complete / Abort  
- Auth: SigV4; auth can be disabled for local development (must be enabled in production)  

Full matrix: [S3 compatibility](../s3-compat.md); usage: [S3 usage](../s3.md).

## Design notes

- **Stateless**: metadata in Store, data in Volume; multi-replica requires shared Postgres/MySQL.  
- Metrics carry an `action` label (including `s3:CreateMultipartUpload`, etc.) for per-API QPS/latency.  
- Helm has only the `opens3-filer` Deployment; S3 is no longer deployed separately.  

## Dependencies

Same crate as Filer: `opens3-store`, `opens3-common`.

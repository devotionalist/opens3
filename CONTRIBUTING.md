# Contributing

**Default language: English.**

- English: [docs/en/contributing.md](docs/en/contributing.md)
- 中文: [docs/zh/contributing.md](docs/zh/contributing.md)

Summary:

- Default branch is **`master`**.
- External changes land **only via pull requests** into `master`.
- PRs need **owner (`@devotionalist`) approval** (CODEOWNERS) before merge.
- **Tags and GitHub Releases** are owner-only.
